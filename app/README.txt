OPERATOR TOOL KIT - DESKTOP APP

Works with no internet. Your inputs are saved on each computer.

WINDOWS
  Double-click "Install on Windows.cmd" (if Windows asks, choose Run).
  Operator Tool Kit goes in the Start menu and on the desktop and opens in its own window.
  To remove it, run Uninstall.cmd in %LOCALAPPDATA%\Operator Tool Kit.

MAC
  Open Terminal, type  sh  and a space, drag "install-mac.sh" into the Terminal window and press Return.
  Operator Tool Kit appears in Launchpad and Spotlight (Applications in your home folder).
  Drag it to the Dock to keep it there. It opens in its own window when Chrome, Edge or Brave
  is installed, otherwise in Safari.

LINUX
  Open a terminal in this folder and run:  sh install-linux.sh
  Operator Tool Kit appears in your app menu. It opens in its own window with Chrome, Chromium,
  Edge or Brave, otherwise in your default browser.

WITHOUT INSTALLING
  Double-click "Operator Tool Kit.html" to use it in any browser.

UPDATES
  When you get a newer copy of this folder, run the installer again. Your inputs are kept.
